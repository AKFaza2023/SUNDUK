# SUNDUK 0.4.0-dev.1

SUNDUK — локальная Windows-программа «всё важное в одном месте», разработка СтавДок.

## Текущий цикл разработки

Общее ядро `Sunduk.Core` отделено от WPF, SQLite-хранилище вынесено в
`Sunduk.Infrastructure`. Добавлены постоянные идентификаторы записей и личного
пространства, версии изменений, мягкое удаление и перенос базы 0.3 с резервной
копией. Русский поиск регистронезависим. Новая база создаётся без демо-записей.

Это кандидат для проверки, а не стабильный релиз. Изменение и удаление записей
пока доступны только через слой хранения. Веб-версия и синхронизация ещё не
реализованы. Часть блоков главной остаётся демонстрационной.

Подробности, ограничения и следующий этап: [цикл 01](docs/CORE_STORAGE_CYCLE01.md).
Утверждённое направление: [Desktop + Web + Sync](docs/decisions/WEB_DESKTOP_SYNC_2026-10-09.md).

## Технологии

- WPF / .NET 8;
- Windows 10/11 x64;
- локальная SQLite-база `%LOCALAPPDATA%\SUNDUK\Data\sunduk.db`;
- self-contained single-file EXE;
- Per-Monitor V2 DPI awareness;
- темы Dark / Light / System без перезапуска.

## Возможности исходной версии 0.3

- фирменная главная страница;
- боковая навигация: Главная, Каталог, Объявления, Закладки, Контакты, Заметки, Ежедневник, Задачи, Напоминания, Файлы, Избранное, Настройки, Поддержка;
- локальный каталог карточек;
- поиск по локальной базе;
- быстрые действия для контакта, закладки и заметки;
- SQLite-хранилище;
- темы Dark / Light / System;
- кликабельная ссылка `ставдок.рф`;
- светлый текст на зелёных акцентных кнопках во всех темах.

## Сборка Windows x64

Требуется .NET 8 SDK.

```powershell
powershell -ExecutionPolicy Bypass -File .\build-release.ps1
```

Результат:

```text
publish\win-x64\SUNDUK.exe
publish\win-x64\SHA256.txt
```
