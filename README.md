# SUNDUK

Рабочий репозиторий проекта **SUNDUK**.

## Статус

Репозиторий инициализирован и подготовлен к разработке. Архитектура и технологический стек будут фиксироваться по мере реализации проекта.

## Базовая структура

- `src/` — исходный код приложения;
- `tests/` — автоматические тесты;
- `docs/` — техническая и проектная документация;
- `assets/` — изображения, иконки и другие ресурсы;
- `scripts/` — служебные скрипты сборки и разработки.

## Правила работы

1. Основная стабильная ветка — `main`.
2. Новые крупные функции рекомендуется разрабатывать в отдельных ветках.
3. Изменения должны сопровождаться понятными сообщениями коммитов.
4. Секреты, ключи, пароли и локальные конфигурации не должны попадать в Git.
