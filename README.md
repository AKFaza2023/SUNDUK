# SUNDUK 0.3

SUNDUK — локальная Windows-программа «всё важное в одном месте», разработка СтавДок.

## Технологии

- WPF / .NET 8;
- Windows 10/11 x64;
- локальная SQLite-база `%LOCALAPPDATA%\SUNDUK\Data\sunduk.db`;
- self-contained single-file EXE;
- Per-Monitor V2 DPI awareness;
- темы Dark / Light / System без перезапуска.

## Уже заложено в 0.3

- фирменная главная страница;
- боковая навигация: Главная, Каталог, Объявления, Закладки, Контакты, Заметки, Ежедневник, Задачи, Напоминания, Файлы, Избранное, Настройки, Поддержка;
- локальный каталог карточек;
- поиск по локальной базе;
- быстрые действия для контакта, закладки и заметки;
- SQLite-хранилище;
- темы Dark / Light / System;
- кликабельная ссылка `ставдок.рф`;
- светлый текст на зелёных акцентных кнопках во всех темах.

## Сборка Windows x64

Требуется .NET 8 SDK.

```powershell
powershell -ExecutionPolicy Bypass -File .\build-release.ps1
```

Результат:

```text
publish\win-x64\SUNDUK.exe
publish\win-x64\SHA256.txt
```
